# Estado do projeto

- **Projeto:** Rota & Conta.
- **Versão:** 1.0.0.
- **Repositório de origem:** `AllyssonEstadulho92/calculadora-aplicativo.-`, inicialmente apenas README.
- **Estado:** implementação local concluída, seis testes de cálculo aprovados, interface e fluxos de comparação/viagem paga/orçamento validados em browser desktop. Publicação privada e PR GitHub em preparação.
- **Funcionalidades:** rota, ofertas Uber/Bolt, intervalos e descontos, sugestão com frescura, cálculo multiplicado por viagens, registos pagos/planeados, relatórios, orçamento, favoritos, CSV/JSON, PWA.
- **Limitações conscientes:** sem preços em tempo real por API, sem OCR, sem mapa incorporado, sem sincronização e sem backend.
- **Riscos principais:** preço mostrado pode mudar após recolha; dados de `localStorage` podem perder-se se o utilizador limpar o navegador; recomendações dependem de inserção correta e momento.
- **Última alteração:** criação do protótipo funcional 1.0.0 a 30/10/2026.
- **Próximo passo:** confirmar comportamento real no iPhone, incluindo instalação PWA e exportação/importação, e definir eventual backup sincronizado entre dispositivos.
